# 📝 Feedback Form

A simple, elegant, and responsive **feedback form webpage** built with **HTML**, **Tailwind CSS**, and **JavaScript**.  
It collects a user's **Name**, **Email**, and **Feedback message**, then displays a friendly **“Thank You”** confirmation after submission.

---

## 🚀 Features

- 🧍 Collects user information: name, email, and feedback message  
- 💫 Smooth animations for form submission and thank-you message  
- 🎨 Clean and modern design using Tailwind CSS  
- 🧩 Split into three separate files (`index.html`, `style.css`, `script.js`) for clarity and maintainability  
- 📱 Fully responsive for all screen sizes
